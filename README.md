

# Team Task Manager

A modern and fully responsive Team Task Manager web application built to streamline project collaboration, task assignment, and productivity tracking for teams and organizations.

The platform allows users to manage projects, assign tasks, monitor progress, and visualize productivity analytics through an elegant dashboard experience.

---

## ✨ Features

### 🔐 Authentication & Authorization
- Secure Login & Signup system
- Role-based access control
- Admin & Member permissions
- Protected routes
- Persistent session handling using Local Storage

### 📊 Dashboard & Analytics
- Interactive analytics dashboard
- Task completion statistics
- Productivity tracking charts
- Overdue and pending task insights
- Real-time project progress indicators

### 📁 Project Management
- Create and manage multiple projects
- Track project completion status
- Team collaboration support
- Project progress visualization

### ✅ Task Management
- Create, edit, and delete tasks
- Assign tasks to team members
- Priority-based workflow
- Task status management
- Due date tracking
- Drag-and-drop Kanban board

### 👥 Team Collaboration
- Team member management
- User roles and permissions
- Activity monitoring
- Assigned task tracking

### 🎨 Modern UI/UX
- Premium SaaS-inspired interface
- Fully responsive design
- Dark & Light mode support
- Smooth animations and transitions
- Professional dashboard layout
- Interactive charts and widgets

# 🚀 Getting Started

## Prerequisites
Make sure you have installed:

- Node.js
- npm or yarn

---

# ⚙️ Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project directory:

```bash
cd team-task-manager
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---
